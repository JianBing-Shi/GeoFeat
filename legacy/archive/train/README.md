# Archived Training Entrypoints

This folder stores historical training entrypoints that are no longer part of the GeoFeat mainline.

- `train.py` at the repository root is the only supported training entrypoint.
- `train_pl.py` was archived after the project converged on a single non-Lightning training path.
- `raw_train.py` was archived because it targets an older pre-GeoFeat training stack and no longer reflects the current model/config pipeline.
